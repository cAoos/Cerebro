# ✍️ Sintaxis básica de Apex

Dos reglas que aplican en todo el código:
1. 🔚 **Cada instrucción termina en `;`**
2. 💬 **El texto va entre comillas simples:** `'Texto'`, nunca `"Texto"`.

## 🧪 Ejemplo
```java
String saludo = 'Hola';   // ✅
String saludo = "Hola";   // ❌ error de compilación
```

Los comentarios también son parte de la sintaxis: ver [[💬 Comentarios en Apex]].
