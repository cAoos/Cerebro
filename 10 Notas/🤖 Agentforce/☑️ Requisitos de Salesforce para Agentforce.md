# ☑️ Requisitos de Salesforce para Agentforce

Si ya eres cliente de Salesforce, el agente debe **convivir con tu configuración actual**. Parte de [[🗒️ Planear un agente]].

| | Consideración |
|---|---|
| 🧾 **Licencias** | Varían por caso de uso: confirmar con el **account executive** |
| 💳 **Facturación** | Modelo **basado en consumo** |
| ✅ **Habilitado en la org** | **Lightning Experience** · **Einstein Generative AI** · **Data 360** |
| 🏢 **Orgs y ambientes** | ¿Cuántas orgs afecta? ¿**Data 360 en el sandbox**? ¿Qué solución de chat tienes? Empezar en **sandbox** suele **ahorrar costos** |
| 🤖 **Einstein Bots** | ¿Cómo se usan y se miden hoy? ¿Qué quieres mejorar con IA generativa? ¿Convertir el bot en agente? Ver [[🆚 Agentforce Service Agent frente a Einstein Bots]] |
| ♻️ **Automatización existente** | Las acciones se construyen sobre **flows, Apex y prompt templates**: **catalogar lo que ya existe** para reusarlo. Ver [[🪛 Reference actions]] |

> ⚠️ Ojo de examen: los tres requisitos para usar Agentforce son **Lightning Experience, Einstein Generative AI y Data 360**. El precio es **por consumo**.
