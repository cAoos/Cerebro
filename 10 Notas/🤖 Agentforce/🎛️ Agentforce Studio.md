# 🎛️ Agentforce Studio

El **centro** para crear, personalizar, probar y **monitorear** agentes. Se abre desde el **App Launcher**.

![[agentforce-studio-paneles.png]]

| | Panel | Qué hay |
|---|-------|---------|
| 🏗️ | **Build** | Tus agentes · **Agentforce Test Suites** · **prompt templates** · datos del agente (**data libraries, retrievers, search indexes**) · elegir los **modelos de IA** |
| 👀 | **Observe** | **Agent analytics**, insights y datos de sesiones reales para optimizar (ver [[📈 Agentforce Observability]]) |
| 🤖 | **Agents** | Lista de todos tus agentes + botón **New Agent** que abre [[🏗️ Agentforce Builder]] |

> ⚠️ Ojo de examen: ¿dónde se configuran las **fuentes de datos** del agente (data libraries, retrievers)? ¿Y el **modelo de IA**? → panel **Build** de Agentforce Studio. ¿Rendimiento en producción? → panel **Observe**.

## 🔁 Repaso #flashcards
¿Qué hay en el panel Build de Agentforce Studio?::Agentes, Test Suites, prompt templates, datos del agente (data libraries, retrievers, search indexes) y la elección de modelos de IA.
¿Qué hay en el panel Observe de Agentforce Studio?::Analytics del agente, insights y datos de sesiones para optimizar su rendimiento.
