# 🏁 Salesforce Go

Un **coach paso a paso dentro de Setup**: dice qué está pasando, qué toca después y cómo hacerlo, todo en un lugar. Se abre desde el engranaje o con **Quick Find > Salesforce Go**, y se busca la funcionalidad (por ejemplo *Agentforce for Sales*).

- ✅ **Enciende de una vez todas las funcionalidades de soporte** en vez de activarlas una por una. Las que ya estaban activas aparecen con check.
- 🗂️ Al activar una plantilla de agente, la tarjeta muestra los **pasos en orden con links**, sin saltar entre secciones de Setup.

## 🛤️ El recorrido para un agente de ventas
![[sdr-proceso-setup.png]]

| Fase | Paso |
|---|---|
| 🟥 Get Ready | 1. **Turn On Agentforce** (requisito para crear, probar y lanzar agentes) |
| 🟪 Set Up Access & Data Library | 2. Activar la plantilla **Engagement** · 3. Accesos para managers y usuarios · 4. Agent user y email · 5. Data library |
| 🟩 Set Up the Agent | 6. **Build and Manage Agent** en **Sales Agent Configuration** (wizard guiado) |

> ⚠️ Ojo de examen: el **primer paso siempre es encender Agentforce**. Salesforce Go es el camino guiado para el setup de [[📮 Agentforce SDR (Engagement agent)]]; lo equivalente en servicio es el setup guiado del [[🆘 Help Agent]].
