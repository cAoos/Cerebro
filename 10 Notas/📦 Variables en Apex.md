# 📦 Variables en Apex

Una variable es un **contenedor de información**. Toda variable necesita:
- 🏷️ **Un nombre único** que describa del todo lo que guarda.
- 🔤 **Un tipo de dato.** Ver [[🔤 Tipos de datos en Apex]].

## 🧪 Ejemplo
```java
Integer i = 2;
```

| Parte | Qué es |
|-------|--------|
| `Integer` | tipo de dato |
| `i` | nombre |
| `2` | valor inicial |

Toda la línea sigue la [[✍️ Sintaxis básica de Apex]]: termina en `;`.

> 💡 `i` sirve para el ejemplo, pero en código real usa nombres descriptivos: `numeroDeContactos`, no `n`.
